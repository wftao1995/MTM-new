# Moment Tensor Potential 文件集

[English](README.md)


本仓库收集优化后的 Moment Tensor Potential（MTP）模板文件、对应的设置及相关数据。文件分为 `ps-1`、`ps-2` 和 `shapeev` 三组。其中，`shapeev` 组采用 Shapeev 的原始基函数定义，并对张量缩并计算路径进行了优化。每组下的目录分别存放一套文件。

## 主要文件

各目录中的文件以实际内容为准，常见文件包括：

- `potential.mtp_0`：MTP 势函数文件。
- `settings.ini`：对应的参数设置。
- `*.dat` 和 `*.log`：相关数据、映射和日志。

使用时请根据需要选择相应目录，并检查该目录中的设置和数据文件。
